# 🚀 My Cybersecurity Journey

Welcome to my personal cybersecurity roadmap and documentation repository! 

## 🎯 Purpose of this Repository
The goal is to track, test, and showcase my progress as I transition into an advanced Penetration Tester and Offensive Security Specialist. I am committed to a strict philosophy:
* **Learn:** Absorb the core concepts, methodologies, and theory.
* **Build:** Practice hands-on in labs, build my own tools, and break configurations.
* **Document:** Write down findings, cheatsheets, and methodologies to reinforce knowledge.

---

## 🗺️ The Offensive Security Roadmap
Below is my structured path from absolute beginner (`0`) to advanced certifications. I am tackling these step-by-step to build a bulletproof foundation.

### 🟩 Phase 1: The Foundations & Fundamentals
*   **[ 0 ] Starting Point:** Networking basics, Linux/Windows administration, and fundamental security concepts.
*   **eJPT** *(eLearnSecurity Junior Penetration Tester):* Grasping the basics of practical penetration testing and assessment methodologies.

### 🟨 Phase 2: Specialization & Professional Skills
*   **eWPT** *(eLearnSecurity Web Application Penetration Tester):* Diving deep into web application vulnerabilities, CMS hacking, and API security.
*   **PT1** *(Practical Junior Cyber Assessment Professional / TCM Security):* Solidifying network pivoting and internal network assessment skills.
*   **PNPT** *(Practical Network Penetration Tester / TCM Security):* Mastering real-world Active Directory exploitation, OSINT, and professional report writing.

### 🟥 Phase 3: The Gold Standards
*   **OSCP** *(Offensive Security Certified Professional):* Conquering the industry-standard 24-hour hands-on exam focused on network and Active Directory exploitation.

### 🟪 Phase 4: Advanced Infrastructure Mastery
*   **OSEP** *(Offensive Security Experienced Penetration Tester):* Evading EDRs, bypassing defense mechanisms, and breaching hardened networks.
*   **CRTO** *(Certified Red Team Operator):* Mastering Command and Control (C2) frameworks, threat emulation, and advanced red team operations.
